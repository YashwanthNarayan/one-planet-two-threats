# One Planet, Two Threats, Our Future

Interactive 3D scrollytelling site on urban heat, wildfire risk, and science-based climate resilience. SUS 103 Group Project Lab.

Custom WebGL engine (no 3D library), React + TypeScript + Vite. All statistics are sourced on-page; 3D transformations are labeled as conceptual illustrations.

## Develop

```
npm install
npm run dev
```

## Build

```
npm run build   # outputs dist/
```

Deployed on Netlify (auto-deploys from the main branch; see netlify.toml).
